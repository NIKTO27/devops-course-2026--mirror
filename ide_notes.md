# Работа с Git в IDE vs CLI

## Удобно в VS Code:
1. Визуальный diff — наглядно видно разницу между старой и новой версиями файлов.
2. Расширение GitLens — сразу видно автора строки и историю коммитов прямо в коде.
3. Удобное разрешение конфликтов слияния (merge conflicts) через встроенный редактор.

## Удобнее в терминале:
1. Выполнение базовых команд (add, commit, push) происходит быстрее и без лишних кликов мышкой.
